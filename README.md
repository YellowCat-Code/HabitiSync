HabitiSync is an unofficial app for Zepp OS that lets you interact with Habitica directly through your watch using the API Habitica provides to each user.

# Features
HabitiZepp is able to recieve all the to-dos, habits, and dailies directly from the user's account using their username and password, and mark them as done in positive and negative (for habits) using only their watches.

# How to try?
**You will need a compatible watch**
Go to the app store inside the Zepp App, look for HabitiSync, and install it. Then, configure your account into the settings app, and open your watch to see the icon.
